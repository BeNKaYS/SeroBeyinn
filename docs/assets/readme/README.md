# README görselleri

## cover.png

SeroBeyinn için üretilmiş kavramsal kapak. Gerçek ürün ekranı değildir.
22 Kasım 2026'da HTML/CSS olarak tasarlanıp headless Chrome 158 ile
1983 × 793 piksel PNG olarak alındı. Marka satırı, başlık ve alt satır
doğrudan CSS metnidir; görselde ayrıca düzenlenmiş bir katman yoktur.

Tasarım tarifi [cover-prompt.txt](cover-prompt.txt) içinde tutulur. Kapak sürüm
numarası veya test sonucu içermez; sürüm güncellenince yeniden üretilmesi gerekmez.

## web-tasks.png

SeroBeyinn Web arayüzünün Görevler ekranını temsil eden 1660 × 850 görsel.
Örnek verilerle düzenlenmiş temsili bir tasarımdır; çalışan uygulamadan alınmış
gerçek ekran görüntüsü değildir. Kişisel veri yoktur.

Gerçek ekran görüntüsü gerektiğinde paket kurulduktan sonra `web ac --read-only
--no-browser` ile açılan arayüz yeni bir headless Chromium oturumunda görüntülenir.
Bu görsel otomatik ajan/hook teslimini kanıtlamaz.
